Permanent Set Bonuses adds reproductions of each armor set bonus as permanent buffs earnable by sustained use of that armor set.

Enemies give experience points when you are wearing an armor set, and when a particular set has accumulated enough experience, a copy of its set bonus will be permanently added to the character. If you continue wearing that armor set, you will not gain any more experience, but you will get the benefit of both the permanent copy bonus and the original set bonus while wearing it.

This is very powerful! Thus, I have attempted to tune the experience amounts to be longer than your typical progression-rush player would want to use that armor set. If you want to be overpowered but have to put in some work for it, or if you just want to incentivize not skipping tiers, this mod might be for you.

Extensive options allow you to enable or disable which set bonuses can become permanent, which will eventually include options to lump similar set bonuses together as a single bonus so you can't get essentially the same bonus several times (e.g. "basic wood armor" "any tier 1 metal"). You can also adjust the experience requirements for each bonus individually. If you set the experience requirement to zero for a set, merely equipping that set will grant its permanent bonus.

If you use a weapon associated with an armor set (usually weapons crafted from the same materials), you get a 10% experience bonus (25% in hardmode). To get experience from an enemy, you must have hit that enemy at least once, and the mod will check which item is being held when the enemy dies to determine experience bonuses.

In its current state, this mod covers most pre-hardmode armor sets: woods except Ash and Pearlwood, and pre-hardmode ores. The next update I plan to add Cactus and Pumpkin armor, and possibly the mage and/or mining sets.
