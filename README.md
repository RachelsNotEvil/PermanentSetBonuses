# Permanent Set Bonuses
A Terraria mod that allows the user to obtain a permanent copy of each armor set's "set bonus" by killing enough enemies while using that armor set.

## Warning: This mod is not yet tested in multiplayer! User feedback on whether it works in multiplayer would be greatly appreciated.

### The current version of this mod supports the following armor sets:
Wood, Palm Wood, Boreal Wood, Rich Mahogany, Ebonwood, Shadewood, Ash Wood, Copper, Tin, Iron, Lead, Silver, Tungsten, Gold, Platinum, Meteor, Shadow, Crimson, Cactus, Pumpkin, Ninja, Wizard, Fossil, Gladiator, Jungle, Bee

### How to gain the permanent set bonus:
Each armor set has an experience amount needed for mastery. Using a special hotkey (default V), you can check the current and needed experience of the armor set you have equipped. Killing enemies with an armor set equipped will add experience to it (critters and NPCs will not give experience). You can get a 10% bonus to experience by also using a weapon associated with the armor set, usually something that is crafted from the same material. For example, the weapons that grant bonus experience for copper armor are copper shortsword, copper broadsword, copper pickaxe, copper axe, copper hammer, copper bow, and amethyst staff. The bonus experience increases to 25% in hardmode.

### Goals for this mod to be considered 1.0:
•Support for every vanilla armor set
•Some minor optimization, eliminating waste that resulted from previous refactors.
•Config options that allows users to combine all of the basic wood set armor bonuses into a single +1 bonus. (In vanilla code, the same set bonus is reused for all wooden armor sets except Ash.)
•Adjust user-facing text to rely more on localizations.
•Hotkey that will allow the fishing armor set's permanent bonus to be toggled on and off.
•Config option that allows user to specify additive and multiplicative exp cost increases for mastering multiple sets.

### Stretch goals (in no particular order):
•Support for other mods on request.
•A wiki that lists each armor set, its default experience requirement, its bonus weapons, and whether the permanent bonus stacks with its original, as well as providing some insight into the mod's underlying mechanics (e.g. bonus weapons are checked similarly to Staff of Regrowth).
•More advanced UI that allows users to check all available set bonuses, not just what is currently equipped.
•More complicated consolidation options, such as a user taking one ore's set bonus locking them out of obtaining the alternate ore's bonus.
•Granting larger set bonuses over multiple mastery levels.
•New bonus for sets that normally do not have one? (e.g. Rain set)
•New "Collector's" armor set with a +1 Luck set bonus
•Optional ability to continue leveling up an armor set in order to unlock each piece's non-set bonuses, for those trying to get even more wildly overpowered.
